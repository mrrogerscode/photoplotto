PhotoPlotto

Turn any image into plotter-ready geometric SVG art.

Controls

Source Image

Choose the image and set the physical drawing size.

Layer Configuration

Build the plotted output as one or more ordered layers. One active layer behaves like the current single-color export.

Tonal Mapping

Control how grayscale values are interpreted before geometry is generated.

Density: darker areas create more marks while line width stays mostly fixed.

Stroke: darker areas create thicker lines with fewer changes in mark count.

Hybrid: darker areas use both more marks and thicker lines.

Geometry Density

Adjust sampling resolution and how much geometry appears in darker regions.

Shape Language

Pick the geometric vocabulary and the rule used to assign forms across the image.

Single Shape: uses one selected shape for every mark.

Intensity Bands: switches shape based on whether an area is dark, midtone, or light.

Seeded Random: mixes enabled shapes in a repeatable random pattern.

Available Shapes

Choose which shapes can appear when using Seeded Random mode.
